# Manual Project Lifecycle Kit

This folder contains only new, fictional demo assets. Use it to create a project from scratch and manually progress it through every currently implemented project and R&R state.

## Start here

1. Start with [project-inputs.md](project-inputs.md).
2. Follow [manual-lifecycle-walkthrough.md](manual-lifecycle-walkthrough.md) exactly.
3. Upload the sample files in `documents/` under the matching category shown in the walkthrough.
4. Read [repository-gap-report.md](repository-gap-report.md) before representing the walkthrough as a fully enforced statutory process.

The samples contain fictional names, identifiers and locations. They are not legal documents and must never be used for a real acquisition.

## Lifecycle covered

`DRAFT → SCRUTINY → SIA → NOTIFIED → STATE_APPROVED → CENTRAL_APPROVED → DECLARED → AWARDED → RR_IN_PROGRESS → POSSESSION → RR_COMPLETE`

The R&R sub-workflow is also covered from `SURVEYED` to `RR_AWARDED`.
